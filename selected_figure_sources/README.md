# Sources for the three user-selected figures

The three PDF files attached on 26 October 2026 are byte-for-byte identical to
Figure_1.pdf, Figure_2.pdf and Figure_3.pdf in the earlier saved
ASAI_Nature_figures_and_PC2_dispersion.zip. The corresponding R script and label
editor are preserved here. Their original numbering maps to Final12 as 1 -> 3,
2 -> 4 and 3 -> 2.

These are reference snapshots. Their earlier numerical inputs differ from the
frozen 6,342-chain dataset and from the current manuscript tables. For example,
the first and last CV values are 2.6995 and 1.4493, while Final12 Table S1 prints
2.866 and 1.558. The received correlation figure prints r = -0.986.
The supplementary-table filenames in this folder retain their historical
numbering and are not the current Supplementary Tables S1-S3.

Use manuscript_tables/ for the current Word-table values and
plot_final12_figures.py for the table-based review figures. No Word-table value
was replaced by a value from these reference snapshots. The R source is supplied
as recovered; R was unavailable and it was not executed in this packaging run.
