# Licence continuity

This update does not replace the existing GitHub repository licence or introduce a different licence for the separately deposited data. When copying these source files into the existing ASAI repository, retain its author-selected `LICENSE` file. Use the corresponding author-selected licence metadata when uploading the code release to Zenodo. Third-party AAindex data retain their source attribution and any applicable source terms. `CITATION.cff` supplies software citation metadata, not a licence grant.
