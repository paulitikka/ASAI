# Additional R source

ASAI_reproduce_stage1.R is the latest separately saved R analysis source.
reconstruct_pisces_dssp_rsa.R is a later DSSP reconstruction program, not the
verified original historical extraction program. It requires current DSSP files
and an explicit maximum-ASA input table and may produce different counts after
database changes. The exact frozen study observations are in the data release.
These optional R programs were not executed in this packaging environment.
